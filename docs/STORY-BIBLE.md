## §0 如何使用本文档

写作任何一条 Statement 前，按以下顺序查表：

1. **查 §6 时间锚点表** —— 确认这个角色在这一章"活到哪一步了"，只能说什么阶段的话。
2. **查 §3.x 该角色的四阶段语料规范表** —— 确认句长 / 标点习惯 / 黑话频率 / 负面清单。
3. **查 §7 黑话分配表** —— 确认该角色在**这一章**允许使用哪几类术语（类别有章节门槛）。
4. **查 §2 语言分层三条铁律** —— 确认这句话是"玩家对话"还是"旁白/系统文本"。
5. **写完查 §8 检查清单**。

**三条不可协商的硬规则（先记住这三条再看别的）**：

- **R1 阶段单向**：角色的成长阶段在**任一角色的时间线上只增不减**。小星在第 3 章不可能说导师期的话（除非它是**错位块**，见 R2）。
- **R2 错位块文本不被改写**：一条语句块的措辞与人格**永远属于它的原始阶段**。玩家把它拖进别的阶段时，**改的是接收方的解读，不是说话人的语气**。所以"导师期的小星说豆芽期的话"是合法的——那不是漂移，那是错位本身。
- **R3 负面清单优先于正面示例**：§3 中每个阶段的"绝不可能说出口的话"，是**否决性**约束。示例语句只是风格样本，负面清单是判据。

## §1 世界观与合规前提

### 1.1 世界设定

- 故事发生在一块**名为「艾欧泽亚」的虚构大陆**上。这里有一群"冒险者"（本作对玩家的世界内称呼）通过**通讯贝**（虚拟聊天频道）与**信件**联络，组成**固定队**与**部队**。
- 全作的"现实层"（玩家在电脑前的真实生活）**从不直接出场**，只通过角色台词里的裂缝被感知（例如夜语说"现实里的我不值得被喜欢"）。这是本作"虚实"主题的形式基础，也是合规的安全边界。
- **「倾听者」** 是玩家的世界内身份：一个能读到不同时空信件、并调整其因果顺序的存在。**全作的旁白/系统文本一律使用倾听者视角的通用语言**，不使用任何黑话（见 §2 铁律一）。

### 1.2 专有名词使用口径（合规）

本作**不使用 FF14 官方 IP**。以下口径为强制执行：

| 词 | 用途 | 口径 |
|---|---|---|
| 艾欧泽亚 | 作品内大陆通称 | **保留**，作为本作自有虚构地名使用，不指向任何官方设定版本 |
| 部队 / FC | 公会组织 | **保留**。信中优先用「部队」，需要体现角色口吻时用「FC」。二者同义，可互换，但**同一封信内不得混用** |
| 通讯贝 / LS / CWLS | 聊天群组 | **保留**。跨服通讯贝固定写「CWLS」；「LS」只在需要区分同服/跨服时使用 |
| 固定队 | 长期组队 | **保留** |
| 职业名（龙骑士、白魔导士、骑士、战士、龙骑、黑魔、赤魔） | 职业原型 | **角色档案与词典条目可写全称**；**信件正文优先使用社区通用简称或位置代称**（T / H1 / H2 / D1 / D2 / 近战 / 治疗 / 奶） |
| 地名（主城、野外、副本、部队房、RP 场所、通讯贝） | 空间标签 | **只用这 6 个通称**，不得出现任何具体官方地图名（如"格里达尼亚""乌尔达哈"等一律禁止） |
| 种族名（拉拉肥等） | 官方种族 | **信件正文禁止出现**。需要时用「那个矮个子队友」「小家伙」等模糊化指称，梗的语义靠语境传达（例：「你再 OT，我就把你当食材炖了。」——不写种族名） |
| 真实 ID / 服务器名 | 玩家标识 | **信件中一律使用角色的花名（晨曦/月见/…）或位置代称（D2、H1、某某）**；服务器统一写「本服」「别的服务器」「跨服」，禁止出现疑似真实 ID 的字符串 |
| 版本号（7.0、6.0 等） | 时间语境 | **仅用于本文档 §6 的内部锚定**，**信件正文禁止出现版本号**。需要表达时间感时用「那会儿」「当年」「这个版本」「上个大版本」 |

### 1.3 内容红线

- 不映射真实玩家 ID、真实部队名、真实服务器事件。
- 不宣扬游戏内负面行为：**退队、骂人、进度欺诈、踢人**等只能作为"被反思的对象"出现，且必须由某个角色承担叙事代价。
- 术语词典条目按**社区通用释义**收录，不引用官方文本原句。

## §2 语言分层三条铁律（源自 PRD §10 / 源 txt §7.3）

### 铁律一 · 语境优先（黑话只活在玩家对话里）

黑话**只**出现在角色**对另一个角色说话**时。以下场景**一律使用通用语言**，一个黑话都不许有：

| 禁止出现黑话的文本层 | 正确写法 | 错误写法 |
|---|---|---|
| 信件标题以外的旁白/场景描写 | 「通讯贝里三天没有新消息。」 | 「通讯贝三天没刷屏了。」 |
| 结尾结算文本 | 「队伍还是散了。」 | 「固定队还是散了，全员退队。」 |
| 评级提示 | 「这一次，你没有让任何人失望。」 | 「完美通关，logs 全金！」 |
| 时空错位预览框 | 「在导师期，这句话可能被解读为一句宽容的劝解。」 | 「在导师期，这句话会被解读成'豆芽慢慢来'。」 |
| 倾听者手记 | 「你成全了她，也松开了另一个人。」 | 「你让她成功上岸，代价是另一个人的 B 结局。」 |
| 词典释义的 brief 字段 | 「最高难度的团队副本。」 | 「比零式还难的那个绝本。」 |

**判定方法**：如果这句话的说话人不是"某个角色"，就不能有黑话。
**例外**：**信件标题**允许黑话（源 PRD 要求，如「关于那个渡劫失败就退队的 D2」）——标题被视作"角色原话的引用"。

### 铁律二 · 可理解性（首次出现轻量注释）

- 每个黑话术语**首次出现时**必须绑定词典条目（校验器 2 会断言"标记为黑话的词，词典中必有条目"）。
- 注释形态：淡金色下划线 + 悬停 tooltip（1 句话，≤ 25 字）；不弹窗、不打断阅读。
- "首次出现"的口径：**按全作信件阅读顺序（L01-01 → H05）的第一个出现点**，而不是按单封信。同一术语在第 2 次及以后出现**不再标注下划线**。
- **首次说出者必须与 §7 的黑话分配表一致**——不能出现"第一个说出'绝本'的人是铃兰"这种事。

### 铁律三 · 角色差异化

三类语言人格，写作时按此归位：

| 语言人格 | 角色 | 用词特征 | 量化 |
|---|---|---|---|
| **老玩家** | 晨曦、烈风、远山、铁壁 | 黑话密度高，且**不解释**（默认对方懂）。术语精确到数字与机制名 | 成熟/导师期 ≥ 3/5 |
| **豆芽 / 成长中** | 小星、早期的铃兰 | 黑话少，**只使用自己听过的词**，用错也正常；会追问术语含义 | 豆芽期 ≤ 2/5 |
| **世界内语言使用者** | **夜语**（含与他对话时的铃兰） | **不使用游戏外术语**，改用世界内表达 | 全程 ≤ 2/5（见 §3.7） |

> **"世界内语言"定义**（夜语专用，其他角色偶尔模仿即为"在逗他"）：
> 不写"我的 RP 角色"，写「我演的那个人」；不写"我开个 RP 号"，写「我想做另一个人」；不写"挂机"，写「就那么待着」；不写"gpose"，写「把那天的样子记下来」。
> **判定**：句子中若出现了"RP / IC / OOC / gpose / 号 / 挂机"等游戏外词，则说话人**不能是夜语**——除非该阶段是夜语的**成熟期**（Ch4），因为"他第一次需要用游戏外术语来描述自己的困境"正是成熟期的核心（见 §3.7）。

## §3 八位角色档案

**主题色使用规则**（对所有角色生效）：

- 角色主题色用于**头像纹章、署名、角色卡片边框**；时间标签色（豆芽=浅绿 `#B7E4C7` / 成长=天蓝 `#9CC7F0` / 成熟=紫 `#B39DDB` / 导师=金 `#FFD166`）用于**语句块左上角 chip**。
- 二者若同族，**明度差必须 ≥ 25%**。唯一冲突点：小星豆芽绿 `#6ECB8B` 与豆芽标签浅绿 `#B7E4C7` —— 已通过纹章加描边解决（见 §3.5）。
- **结局名跨角色重名处理**：`缺口`（晨曦 B / 铁壁 B）、`独行`（晨曦 C / 烈风 B）、`疲惫`（月见 C / 铁壁 C）三组重名是**允许**的（结局名在同一角色的命名空间内唯一）。但 **UI 与文本引用时必须写成「晨曦·B 缺口」形式**，禁止裸写"缺口结局"。

#### 语义弧光（以「机制我吃，你们放心打」为轴）

同一句话，在四个阶段是四件不同的事：

| 放置阶段 | 这句话此刻的意思 | 接收方的感受 |
|---|---|---|
| 豆芽期 | **逞强**——豆芽期的晨曦根本没有吃机制的能力，这句话在这个阶段是虚张声势，会被老玩家当笑话 | 尴尬 / 好笑 |
| 成长期 | **誓言**——我替你挨，你只管打 | 安心 |
| 成熟期 | **分工**——不是"我扛"，而是"我来安排谁扛" | 被安排，而不是被保护 |
| 导师期 | **让位**——"这次你来吃，我在旁边看着" | 被信任 |

> **写作规则**：这四层含义**不能在一封信里同时出现**。每封信只能兑现其中一层，且必须与该信的时间锚点一致。

#### 语义弧光（以「对不起，是我奶慢了」为轴）

| 放置阶段 | 指向 | 含义 |
|---|---|---|
| 豆芽期 | **指向自己** | 她真的认为这是自己的错 |

| **社区身份** | 铃兰（通讯贝） | 夜语在铃兰的通讯贝里基本不说话。他不是不参与，他是**不需要用说话来确认自己的存在**——这一点让铃兰既欣赏又难受。 |

#### 语义弧光（以「我可以扮演任何人」为轴）

| 放置阶段 | 这句话此刻是什么 | 说明 |
|---|---|---|
| 豆芽期 | **逃离** | 我可以不做我 |
| 成长期 | **沉溺** | 我更喜欢那个人 |
| 成熟期 | **恐惧** | 我回不去了 |
| 导师期 | **授权** | 你也可以选择做谁——从"我逃"到"我许" |

> **与铃兰的互文**：夜语导师期「你扮演的角色，也是你的一部分」 ↔ 铃兰导师期「倾听本身就是一种陪伴」。两句互换 → 触发共存结局「时间之外」（"你教我的，我教给了未来的你"）。
> **写作硬规则**：这两句话**必须能互相回答**。夜语那句回答的是"我是谁"，铃兰那句回答的是"我在不在"。互换后仍然通顺，是校验「时间之外」素材质量的唯一标准。

## §6 时间线一致性规范

### 6.1 铁律：阶段单向推进

- 每个角色有一条**个人时间线**。其锚点阶段在章节序列上**非递减**（见 §5.2 表）。
- **禁止出现"导师期的小星引用尚未发生的事件"**。判定方式见 §6.3 的事件年表。
- **禁止阶段回退**：小星不能在 Ch4 用豆芽期的语气讲当章主线台词。若一段文本读起来像豆芽期，它必须确实是**错位块**（携带豆芽期原坐标），而不是一条"当章新写的、模仿豆芽语气的"台词。

### 6.2 绝对时间锚点表（世界内事件序号）

所有信件、语句块、结局文本中的事件引用，都按这张表定序。**表内序号是唯一的绝对时间**。

| 序号 | 事件 | 对应章 | 涉及角色 |
|---|---|---|---|
| T0 | 各角色入坑（时间点不同，属个人前史） | 前史 | 全体 |
| T1 | 晨曦组建固定队；小星入坑并被铁壁招进部队 | **Ch1** | 晨曦 · 月见 · 烈风 · 小星 · 铁壁 |
| T2 | 烈风退出晨曦的固定队；小星第一次被带本；铃兰建立 CWLS | **Ch2** | 烈风 · 晨曦 · 月见 · 小星 · 铁壁 · 铃兰 |

### 6.3 合法性判据

**判据 A（当章主线语句）**：
> 第 N 章一条**非错位**的语句块，其内容只能引用事件序号 **≤ N** 的事件。
> 例：Ch2 的 L02-05「不踢AFK」中，铁壁不得提"远山回来了"（T3 > Ch2）。✗

**判据 B（错位块）**：
> 错位块的**内容可以引用任意事件**（这正是错位的意义），但**接收方角色不得表现出理解**。接收方只能有这三种反应：
> 1. **读不懂** ——「……这是什么意思？」
> 2. **误解** ——把未来的话当作玩笑、挑衅、或无关的话
> 3. **被击中但说不清** ——感到难受/温暖，但归因错误
> **禁止**接收方准确复述错位块的来源时空。角色永远不知道自己在被错位。

**判据 C（阶段 → 块的可用性）**：见 §5.2 的块可用性规则。

**判据 D（错位距离不决定结局好坏）** —— *本判据已于 PRD 裁定 #8 推翻，旧版本要求"Δt≥3 恒为崩坏"，是错的。*

> 错位分档**只由 `(Δt, Δs)` 二元组决定，没有"自动崩坏"这一档**：
>
> | Δt | Δs | 档位 |
> |---|---|---|
> | 0 | 0 | `reorder` |
> | 0 | >0 | `microshift` |
> | >0 | 0 | `transform` |
> | >0 | >0 | `high` |
>
> 因此「豆芽期 → 导师期」（Δt=3, Δs=0）判为 **`transform`（语义质变 / 成长·回忆·传承）**，
> **不是崩坏**。这正是本作的头号卖点——核心体验原句就是「把一句豆芽时期的怯懦提问，
> 拖进导师期的庆功宴」。若把它判成失败状态，游戏最好的一刻就没了。
>
> 「因果崩坏」是信件**主动选择的结局**（评级 `X`），不是坐标自动推导出的状态。
> 全书应当**只有 H03「首杀那天的语音」**走向崩坏；其余 `high` 档信件应走向隐藏剧情。
>
> **写作建议（是建议不是禁令）**：`transform` 档距离越远，张力越强。
> Δt=1 适合温情；Δt=3 适合"说话人已经认不出当年的自己"这种更重的东西——
> 但它依然可以是温柔的，只要那是你想写的。

**判据 E（同一封信内的阶段纪律）**：
> 一封信内，**同一个角色的块只能出现一次**。不允许同一角色在同一封信里既有豆芽期块又有导师期块——那会让"谁在说话"失焦。跨阶段对话必须发生在**不同角色之间**，或**同一角色的块 vs 他人的解读**之间。

### 6.4 阶段错位的语义档位速查（写作时直接照抄）

| Δt | Δs | 档位 | 结局语义库 | 写作口径 |
|---|---|---|---|---|
| 0 | 0 | reorder | 原判定逻辑 | 正常的同场景重排，无时空异样感 |
| 0 | >0 | microshift | 环境冲突 | 同一句话在"副本里说"和"部队房里说"被解读成两件事 |
| 1 | 0 | transform | 成长 / 回忆 / 传承 | **本作最主要的错位档**，温情向首选 |
| 2 | 0 | transform | 成长 / 回忆 / 传承 | 张力更强：说话人已经不认识当年的自己 |
| 3 | 0 | transform | 成长 / 回忆 / 传承 | 豆芽期 → 导师期。**仍是质变档，不是崩坏**（PRD 裁定 #8）——这正是本作的头号卖点 |
| >0 | >0 | high | 隐藏 / 崩坏 | 隐藏信与终章。**默认写隐藏剧情，除非该信明确要写崩坏** |

> **没有 `collapse` 档位。** 「因果崩坏」是信件可以主动选择的结局评级 `X`，
> 不是由坐标自动推导出的状态。全书只应有 H03 一封走向崩坏。

## §8 写作检查清单

每写完一封信，逐条对照。**任一条不通过，此信不得提交。**

1. **阶段锚点**：这封信的主锚点阶段，是否等于 §5.2 表中该角色在该章的锚点？（错位块除外，且错位块必须显式携带原始坐标）
2. **黑话频率**：逐角色数一遍，这封信里该角色使用的黑话条数，是否落在 §3.x 表给定的频率区间内？
   - 1/5 ≈ 每封信 ≤ 2 条术语，且限清单内词
   - 2/5 ≈ ≤ 3 条
   - 3/5 ≈ 3~5 条
   - 4/5 ≈ 4~7 条
   - 5/5 ≈ 5~9 条，且**不解释、不迟疑**
3. **出处可溯**（小星专用）：小星说的每一个术语，是否能在 §7.4 找到出处？
4. **类别门槛**：这封信里出现的每个术语，其类别是否已在**本章或更早**引入？（§7.1）
5. **负面清单**：逐角色过一遍 §3.x 的"绝不可能说出口的话"，有没有踩线？
6. **旁白纯净**：所有非角色对话的文本（场景描写、结算、评级提示、预览框、倾听者手记）是否**一个黑话都没有**？（§2 铁律一）
7. **首次注释**：本信是否引入了新的黑话？如有，是否绑定了词典条目，且下划线仅在**全作首次出现处**标注？
8. **语义弧光**：这封信是否推进了**至少一位角色**的语义弧光？推进方式是"该角色的轴心句在此阶段兑现了某一层含义"，而不是"提到了那件事"。**一封信里最多兑现两条弧光**——超过两条会稀释。
9. **事件序号**：这封信里引用的所有事件，序号是否 ≤ 本章？（§6.3 判据 A）错位块是否遵守了"接收方不得理解"？
10. **关系约束**：这封信是否触发了 §4.2 的某条硬约束？特别是：
    - 铃兰是否是两角色首次跨圈接触的中介？
    - 晨曦是否**没有**引用月见的判断？
    - 月见与铃兰是否**没有**同处一封信？
11. **重名消歧**：若涉及结局名，是否写成「角色·评级 结局名」（如「晨曦·B 缺口」）而非裸名？
12. **可拖动性**：本信的可拖动块 M ≤ 4，总块数 N ≤ 6？（PRD §4.1 硬约束）
13. **舞台说明**：本信的每个块，是否都能明确回答"谁、在哪个空间、以什么姿态说出这句话"？答不出来的块直接删。
14. **一句话测试**：用一句话说出"这封信改变了谁的什么"。说不出 → 这封信没有存在价值，删掉或合并。

### B1 · 隐藏信 H01 的错位档与其所在章的解锁能力冲突

- 源 txt §6.2 要求 H01「给未来的自己」用"豆芽期语句拖入成熟期"；但 PRD §8 规定**第一章只解锁"仅同阶段重排"**。校验器 14（新机制前置）会直接断言失败。

- **临时口径（本圣经采用）**：H01 在 Ch1 内一律为**豆芽期块**，"给未来的自己"是**信件内容层面的设定**（小星写给未来自己的信），不是一次可执行的跨时间拖动。可执行的跨时间版本移到 Ch5 与时空沙盘。

### B2 · 隐藏信 H02 同理，且 Δt=3

### B3 · 共存结局「双向奔赴」的触发条件含 Δt=3 —— **已由裁定 #8 解决**

- ~~PRD §5.5 要求把"小星导师期语句拖入铁壁豆芽期信件"（Δt=3）；但 PRD §4.3 规则 1 规定 offset ≥ 3 恒判 `collapse`。~~
